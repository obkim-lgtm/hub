CLIPO 이용 분석 리포트

목업 화면 URL 인덱스

BENCH C

CLIPO · 26년 하반기

선생님이 수업을 만들고 채점하고 기록하는 흐름을 화면으로 먼저 돌려 봐요.

📚
클리포 수업
수업 홈 → 수행평가 설계 → 과제물 관리 → 수행평가 채점까지 선생님 전체 흐름. 빈 양식 업로드·학급 PDF 일괄 업로드·OCR 확인 필요 수정·자동 확인완료까지 탭으로 한 바퀴.
⚡
세특 간편 생성기 (개발본)
실제 개발 화면·피그마 기준 3~5단계 (키워드 및 활동 입력 / AI 기록 생성 / 기록 편집). 개별 자료 업로드+AI 분석, 기록 다듬기 포함. 스텝바로 단계 이동.
📝
창의적 체험활동
자율·진로·동아리·봉사 활동 누가기록. 목록 → 학생 자료 입력 → AI 콘텐츠 요소 선택 → 기록 확인·수정 3단계 흐름.
💳
이용권 관리
크레딧 정책(v0.7)은 유지, 크레딧 정보 표시 UI 변경 — 데일리/종량제 잔여·만료·차감을 한눈에 정리.
🎒
초등 채점·결과 공개
학급 채점 현황 → 학생별 채점 → 결과 공개(학생 화면/PDF) 전체 흐름. 김피드백·미제출·채점실패 등 케이스 포함.
BENCH C′

CLIPO · 다음 차례

아이디어 단계이거나 일정이 뒤로 밀려 잠시 대기 중인 화면이에요.

🖥️
화면 이탈 집중 로그
직접 제출 중 다른 탭·창으로 이동한 기록을 남기는 컨셉. 학생 사전 고지 → 제출 중 실제 이탈 감지 → 교사 제출 현황 이탈 로그 열. 판정 없이 사실만 기록.
⚡
AI 채점 옵션 목업
"AI 결과 너무 길다" 피드백 반영 — 채점 실행 옵션(모드·모델·이전 채점 참고) → 빠른 채점 학생 상세(총평+한 줄 근거, Enter로 넘김) → 재실행 옵션(부분 재채점·AI 요청 프롬프트).
🔀
겸임 · 복수 학교
한 계정으로 복수 학교 워크스페이스 — 헤더 학교 스위처, 소속 학교 카드(교과·권한·인증), 학교 추가 / 소속 정리 분기, 이용권 귀속 라벨(모든 학교 공용·특정 학교 전용).
🏫
소속 변경 · 데이터 보존
학교를 옮길 때 학생 정보는 비식별화 보존, 작업물은 유지. 내 정보 → 소속 변경 → 보존 동의 → 재인증 흐름. 이전 학교 자료는 읽기전용 아카이브(수업/기록 탭, 학교 스위처)로 열람.
⚡
세특 간편 생성기
교과·그룹 정보를 분리하고 3단계로 재구성한 목업. 일정상 6/25 배포에서는 제외됨.
